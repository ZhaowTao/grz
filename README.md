# Dawn — 3D Creator Portfolio

A dark-themed 3D creator portfolio landing page built with React, TypeScript,
Tailwind CSS, Framer Motion, and Lucide React.

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS 3
- Framer Motion 12 (scroll-driven marquee, sticky stacking cards, text reveal)

## Run locally

```bash
npm install
npm run dev
```

Dev server runs at http://localhost:3000.

## Build

```bash
npm run build
```
